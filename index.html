An open letter, and a plan

The internet was built as a commons. Five companies run it now.

We did not lose the web in a single moment. We handed it over one convenience at a time. This project is an argument that the loss is reversible, and a public attempt to prove it by building in the open, every day, where anyone can watch.

The diagnosis

Four things broke at once.

None of these were inevitable. Each was a business decision, made by people, that can be answered by other people making different ones. Naming them precisely is the first step, because a problem described only as a mood cannot be fixed.

Problem 01

The feed replaced the choice

You used to decide what you read. Now a ranking model decides, and it is not optimising for whether you are better off afterwards. It is optimising for whether you stay.

Problem 02

Surveillance became the price

Reading a page should not create a permanent record of you. Somewhere along the way, being watched stopped being a bug and became the business model of the entire web.

Problem 03

The record is rotting

Links die. Platforms close and take a decade of writing with them. We are the first civilisation whose public memory can be deleted by a company going out of business.

Problem 04

Volume is drowning craft

Generated filler is cheap and infinite. Careful human work is neither. Without a way to find the second kind, the first kind wins by sheer weight.

The web is not a place you visit. It is a thing you are allowed to make. The premise of this project

Nostalgia is not a strategy. Nobody is going back to 1998, and nobody should want to. The old web was small, hard to use, and open to a narrow group of people who already knew how it worked.

What is worth recovering is not the aesthetic. It is the assumption underneath it: that an ordinary person could own a corner of the internet outright, and that nobody could take it away, throttle it, or quietly stop showing it to anyone.

The response

Three commitments.

This project is deliberately small in scope and stubborn about it. It does the following three things and refuses the rest, because campaigns that try to fix everything fix nothing.

  1. Make ownership the default again

    Practical, unglamorous help for getting people onto their own domain, with their own archive, in formats that outlive whoever is hosting them. Not a platform. A set of instructions anyone can follow in an afternoon.

  2. Keep the receipts

    Document what is being lost while it is being lost. Broken links, closed platforms, policy changes that quietly narrow what people can say or see. A public record makes vague unease into something you can point at.

  3. Work in the open, daily

    Every decision, dead end and reversal gets written down the day it happens. If this project fails, the log should be useful enough that the next attempt starts further along than this one did.
